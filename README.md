# Payment Broadcast Bot (example)

Концепт бота для платных подписок/платежей и рассылок. Проект приведен в качестве примера структуры; работоспособность не гарантируется.

## Кратко о проекте
- Telegram-бот (aiogram) + Django-бэкенд
- Поддержка платежных провайдеров, рассылки по группам
- Планировщик задач (cron) для периодических проверок

## Структура
- `bot/` — логика бота, команды, платежные сценарии
- `payment/`, `posting/`, `users/` — Django-приложения
- `core/` — настройки Django
